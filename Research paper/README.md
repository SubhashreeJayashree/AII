## Quick Start

1. **Open the Application**
   - Simply open `index.html` in your web browser
   - No installation required!

2. **Start Coding**
   - Type code in the **Code Editor** (left panel)
   - Click **Run** to execute
   - Or type commands directly in the **FlowLang Shell** (right panel)

3. **Use AI Assistant**
   - Toggle **AI Mode** ON
   - Ask AI to build, fix, or improve your code
   - AI can correct spelling mistakes and fix errors automatically

## Example Code

```simplelang
say "Hello, SimpleLang!"

make name "Alice"
make age 25
say name
say age

make total 10 + 20
say total

ask "What is your name?" yourname
say yourname
```

## Language Syntax

### Only 3 Commands!

1. **SAY** - Display text or numbers
   - `say "Hello"`
   - `say 10`
   - `say myname`

2. **MAKE** - Create variables
   - `make name "John"`
   - `make age 25`
   - `make total 10 + 20`

3. **ASK** - Get user input
   - `ask "What is your name?" name`
   - `say name`
