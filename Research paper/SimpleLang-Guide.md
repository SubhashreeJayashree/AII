# SimpleLang - The Simplest Programming Language

## Only 3 Commands!

SimpleLang is the **simplest programming language in the world** - you only need to learn 3 commands!

---

## The 3 Commands

### 1. SAY - Display Text or Numbers

**Syntax:**
```
say "text"
say number
say variable
```

**Examples:**
```
say "Hello World"
say 42
say myname
```

---

### 2. MAKE - Create Variables

**Syntax:**
```
make name value
```

**Examples:**
```
make name "John"
make age 25
make total 10 + 20
```

---

### 3. ASK - Get User Input

**Syntax:**
```
ask "question" name
```

**Examples:**
```
ask "What is your name?" name
say name
```

## That's It!

Only 3 commands:
- **say** - Display
- **make** - Create variable
- **ask** - Get input

No loops, no conditionals, no complex syntax - just these 3 simple commands!

---

## Tips

- Use quotes for text: `"Hello"`
- No quotes for numbers: `10`
- Use `make` to store values
- Use `say` to display anything
- Use `ask` to get user input
