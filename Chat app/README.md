# AI Social Clone

Responsive starter with feed, messages, WebRTC calls, voice-note uploads, OpenAI transcription, and Telegram/Instagram hooks.

Quick start (PowerShell):
1. Install dependencies:
   npm install

2. Copy .env:
   copy .env.example .env
   notepad .env   # add OPENAI_API_KEY and TELEGRAM_BOT_TOKEN

3. Start server:
   npm start

Open http://localhost:3000 in a browser.
